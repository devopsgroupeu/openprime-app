# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, pull requests or discussions.

Report them privately through GitHub instead: on the [Security tab](https://github.com/devopsgroupeu/openprime-app/security) of this repository, click **Report a vulnerability**, or open the [advisory form](https://github.com/devopsgroupeu/openprime-app/security/advisories/new) directly. If you cannot use GitHub, email [security@devopsgroup.sk](mailto:security@devopsgroup.sk).

Please include what is affected, how to reproduce it and what an attacker could achieve with it.

## Supported versions

Fixes are released from `main` as a new version; older releases are not patched. Please stay on the latest release.
